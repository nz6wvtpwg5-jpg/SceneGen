ROOT CAUSE ANALYSIS
================================================================================

The REQUEST_DENIED error from Google Directions API, despite:
- API being enabled
- Billing being enabled
- Key being unrestricted

This typically indicates ONE of the following:

1. **API KEY QUOTA/LIMITS ISSUE**
   - The Directions API may have per-API quotas that need to be increased
   - Default quota might be 0 requests/day until manually increased

2. **API KEY NOT PROPERLY LINKED TO ENABLED API**
   - The API is enabled in the project
   - But the specific API key may not have permission to use it
   - This can happen with older keys when new APIs are enabled

3. **GOOGLE CLOUD PROJECT VERIFICATION REQUIRED**
   - Some APIs require additional verification steps
   - The project may need to be verified for production use

4. **BILLING ACCOUNT NOT LINKED TO PROJECT**
   - Billing might be "enabled" but not linked to this specific project
   - Or linked incorrectly

5. **API KEY CACHED/STALE**
   - Google's systems may be caching an old version of the key
   - Can take up to 5 minutes to propagate changes
