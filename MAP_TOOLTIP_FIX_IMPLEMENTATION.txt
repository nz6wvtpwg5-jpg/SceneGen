STEP 3: Added Pixel Position Calculator
---------------------------------------
NEW FUNCTION: getPixelPosition(lat, lng)

Purpose: Converts geographic coordinates to screen pixel coordinates

How it works:
1. Gets map projection from Google Maps API
2. Gets current map bounds
3. Calculates pixel position based on zoom level
4. Returns {x, y} coordinates relative to map container

Formula:
- Uses map.getProjection().fromLatLngToPoint()
- Applies zoom scale: Math.pow(2, zoom)
- Calculates offset from bounds

STEP 6: Added Custom Tooltip Overlay
------------------------------------
NEW JSX BLOCK after GoogleMap:

```tsx
{hoveredShow && tooltipPosition && (
  <div
    style={{
      position: 'absolute',
      left: tooltipPosition.x,
      top: tooltipPosition.y,
      transform: 'translate(-50%, -110%)',
      zIndex: 1000,
      pointerEvents: 'auto',
    }}
    onMouseEnter={handleTooltipMouseEnter}
    onMouseLeave={handleTooltipMouseLeave}
  >
    <MarkerTooltip ... />
  </div>
)}
```

Positioning Logic:
- position: absolute (relative to map container)
- left/top: Pixel coordinates from getPixelPosition()
- transform: translate(-50%, -110%)
  * -50% centers tooltip horizontally on marker
  * -110% positions tooltip above marker with small gap
- zIndex: 1000 (ensures tooltip appears above map elements)
- pointerEvents: auto (allows mouse interaction with tooltip)

================================================================================
HOW IT WORKS
================================================================================

USER INTERACTION FLOW:

1. User hovers over marker
   ↓
2. onMouseOver fires → handleMarkerMouseOver(show)
   ↓
3. getPixelPosition() calculates screen coordinates
   ↓
4. tooltipPosition and hoveredShow states update
   ↓
5. React renders custom tooltip div at calculated position
   ↓
6. User sees tooltip appear above marker
   ↓
7. User moves mouse to tooltip
   ↓
8. onMouseEnter fires → handleTooltipMouseEnter()
   ↓
9. Close timeout is cancelled, tooltip stays open
   ↓
10. User moves mouse away from tooltip
    ↓
11. onMouseLeave fires → handleTooltipMouseLeave()
    ↓
12. Tooltip immediately closes

ANTI-FLICKER MECHANISM:

- 200ms delay between marker mouseOut and tooltip close
- Delay is cancelled if mouse enters tooltip
- Provides smooth transition from marker to tooltip
- No flickering even with fast mouse movements

CUSTOMIZATION OPTIONS
================================================================================

ADJUST TOOLTIP POSITION:
------------------------
In the transform property:

translate(-50%, -110%)
         │      │
         │      └── Vertical: -110% = above marker
         │          -50% = slightly above
         │          10% = below marker
         │
         └── Horizontal: -50% = centered
                        -100% = left-aligned
                        0% = right-aligned

PREVENT TOP CLIPPING:
---------------------
If tooltip clips at top of screen, change vertical offset:

From: transform: 'translate(-50%, -110%)'
To:   transform: 'translate(-50%, 10%)'  // Below marker

Or add smart positioning logic:

```tsx
const isNearTop = tooltipPosition.y < 400;
const verticalOffset = isNearTop ? '10%' : '-110%';
transform: `translate(-50%, ${verticalOffset})`
```

ADJUST CLOSE DELAY:
-------------------
In handleMarkerMouseOut():

setTimeout(() => { ... }, 200)
                        └── Change this value
                            100 = faster close
                            300 = more lenient

CHANGE TOOLTIP DIRECTION:
-------------------------
Add logic to position tooltip based on available space:

```tsx
const getTooltipTransform = () => {
  if (tooltipPosition.x < 200) return 'translate(0%, -50%)'; // Right
  if (tooltipPosition.x > windowWidth - 200) return 'translate(-100%, -50%)'; // Left
  if (tooltipPosition.y < 400) return 'translate(-50%, 10%)'; // Below
  return 'translate(-50%, -110%)'; // Above (default)
};
```

TROUBLESHOOTING

ISSUE: Tooltip not appearing
SOLUTION: Check that mapRef.current is set in onLoad callback
          Verify getPixelPosition returns valid coordinates

ISSUE: Tooltip in wrong position
SOLUTION: Check map projection is available
          Ensure map is fully loaded before calculating position
          Verify transform values are correct

ISSUE: Tooltip still flickers
SOLUTION: Increase delay in handleMarkerMouseOut (try 300ms)
          Check that handleTooltipMouseEnter is cancelling timeout
          Verify pointer-events: auto is set

ISSUE: Tooltip clips at screen edge
SOLUTION: Implement smart positioning (see customization above)
          Or add overflow: visible to parent container

ISSUE: Tooltip doesn't close
SOLUTION: Verify handleTooltipMouseLeave is firing
          Check that states are being cleared
          Ensure no event propagation issues
