ISSUE CONFIRMED: HTTP Referrer Restrictions Blocking Localhost
Last Updated: April 7, 2026
================================================================================

⚠️ CRITICAL FINDING ⚠️

The API works perfectly when tested directly in the browser:
https://maps.googleapis.com/maps/api/directions/json?origin=Atlanta&destination=New+York&key=YOUR_API_KEY

Result: "status": "OK" with full route data

BUT the same API call from your TourMap app returns: REQUEST_DENIED

================================================================================
ROOT CAUSE IDENTIFIED
================================================================================

❌ YOUR API KEY HAS HTTP REFERRER RESTRICTIONS
❌ LOCALHOST IS NOT IN THE ALLOWED REFERRERS LIST
❌ GOOGLE IS BLOCKING YOUR APP'S REQUESTS

When you test in browser directly:
✅ Request has no referrer restriction
✅ Google allows it
✅ Returns valid data

When your app makes the request:
❌ Request comes from http://localhost:3000
❌ Referrer doesn't match API key restrictions
❌ Google blocks it with REQUEST_DENIED

================================================================================
THE FIX (Choose Option A or B)
================================================================================

OPTION A: ADD LOCALHOST TO ALLOWED REFERRERS (Recommended for Dev)
-------------------------------------------------------------------

1. Go to: https://console.cloud.google.com/apis/credentials

2. Click on your API key to edit it

3. Under "Application restrictions":
   - Select "HTTP referrers (web sites)"

4. Under "Website restrictions", click "ADD AN ITEM" and add:

   http://localhost:3000/*
   http://127.0.0.1:3000/*
   http://localhost:*

   (Add all three to cover all bases)

5. Click "SAVE"

6. ⏱️ WAIT 5-10 MINUTES for Google to propagate changes

7. Restart your dev server:
   npm run dev

8. Hard refresh browser (Cmd+Shift+R or Ctrl+Shift+F5)

9. Test the tour map again


OPTION B: TEMPORARILY REMOVE ALL RESTRICTIONS (Quick Test)
-----------------------------------------------------------

1. Go to: https://console.cloud.google.com/apis/credentials

2. Click on your API key to edit it

3. Under "Application restrictions":
   - Select "NONE"

4. Under "API restrictions":
   - Select "Don't restrict key"

5. Click "SAVE"

6. ⏱️ WAIT 5-10 MINUTES

7. Restart dev server and test

⚠️ WARNING: This makes your key insecure. Only use for testing!
⚠️ After confirming it works, add proper restrictions back

================================================================================
WHY THIS HAPPENS
================================================================================

Google Maps API validates requests based on:

1. WHERE the request comes from (referrer/domain)
2. WHICH APIs are allowed to be called
3. IP address restrictions (if set)

Your API key was configured to only allow requests from specific domains.
Since localhost wasn't in that list, all requests were blocked.

The browser direct test worked because:
- No referrer header was sent
- Google treated it as a simple API test
- Restrictions weren't applied

Your app's requests failed because:
- Browser sends referrer: http://localhost:3000
- Google checks API key restrictions
- localhost not in allowed list
- Request blocked with REQUEST_DENIED

PRODUCTION DEPLOYMENT NOTE
================================================================================

When you deploy to production, remember to:

1. Add your production domain to allowed referrers:
   https://yourdomain.com/*
   https://www.yourdomain.com/*

2. Keep localhost in the list if you want to keep developing

3. OR create separate API keys:
   - Development key: localhost only
   - Production key: your domain only

4. Use environment variables to switch between them:
   - .env.local (dev key)
   - .env.production (prod key)
