================================================================================
POSSIBLE ROOT CAUSES (Ranked by Likelihood)
================================================================================

1. API KEY QUOTAS/LIMITS (HIGH PROBABILITY)
   -----------------------------------------
   Symptoms Match:
   - REQUEST_DENIED often indicates quota exceeded
   - New projects have restrictive default quotas

   Default Quotas:
   - Directions API: 2,500 requests/day (FREE tier)
   - After free tier: ~$5 per 1,000 requests

   Your Tour:
   - 28 shows = 1 API request (1 segment under 25 waypoints)
   - Should be well within limits

   Possible Issues:
   - Quota may be set to 0 for Directions API
   - Daily quota may have been exhausted by testing
   - Per-user quota restrictions enabled

   SOLUTION: Check quota settings in Google Cloud Console

2. API KEY SETUP TIMING (MEDIUM PROBABILITY)
   -------------------------------------------
   Symptoms:
   - API shows as "enabled" but key was created before enabling
   - Key may not have permissions propagated

   Timeline Issue:
   - If API was enabled AFTER key creation
   - Key might not have been granted access

   SOLUTION: Create a fresh API key AFTER confirming API is enabled

3. PROJECT CONFIGURATION (MEDIUM PROBABILITY)
   --------------------------------------------
   Issues:
   - Wrong project selected in console
   - API enabled in different project than key belongs to
   - Billing account not linked to correct project

   SOLUTION: Verify project ID matches across:
   - API enablement page
   - Credentials page
   - Billing page

4. REGIONAL RESTRICTIONS (LOW PROBABILITY)
   -----------------------------------------
   Some Google APIs have geographic restrictions
   - Check if Directions API has country limitations
   - Check if your billing address matches service region

   SOLUTION: Check API service availability for your region

5. SERVICE ACCOUNT PERMISSIONS (LOW PROBABILITY)
   -----------------------------------------------
   If using service account credentials
   - May need additional IAM permissions
   - May need to enable domain-wide delegation

   SOLUTION: Use browser API key instead of service account
