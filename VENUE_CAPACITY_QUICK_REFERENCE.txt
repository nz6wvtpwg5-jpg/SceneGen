## How to Set Capacity

### 1. When Creating Show:
```
Create Show Form
  ↓
Venue Info Section
  ↓
Capacity Field (optional)
  ↓
Enter number (e.g., 500)
  ↓
Save Show
```

### 2. When Editing Show:
```
Tour Page → Shows Tab
  ↓
Click Edit on any show
  ↓
Update Capacity field
  ↓
Save Changes
```

### 3. Via Day Sheet:
```
Tour Page → Routing Tab
  ↓
Click map marker
  ↓
Click Edit
  ↓
Update Capacity
  ↓
Save
```
