1. PROJECT OVERVIEW
================================================================================

SceneGen is a comprehensive platform designed to connect artists, promoters,
and venues in the live music industry. The MVP focuses on core networking,
show management, and tour organization features.

KEY OBJECTIVES:
- Facilitate connections between artists, promoters, and venues
- Streamline show booking and tour management
- Provide real-time messaging and notifications
- Enable search and discovery of music industry professionals

TARGET USERS:
- Artists/Bands seeking bookings
- Promoters organizing shows
- Venues hosting events
- Music industry professionals

ARCHITECTURAL PATTERNS:

   - Use 'use client' only when necessary
   - Minimize client-side JavaScript

   - Frontend calls /api/* routes
   - API routes proxy to backend services
   - Handles authentication & error transformation
   - Enables request/response transformation

3. Component Composition
   - Small, focused components
   - Reusable UI primitives from shadcn/ui
   - Custom business logic components
   - Separation of concerns

4. Type Safety
   - TypeScript throughout
   - Generated types from OpenAPI specs
   - Strict type checking enabled

5. Progressive Enhancement
   - Server-side rendering by default
   - Client-side interactivity where needed
   - Graceful degradation

================================================================================

AUTHENTICATION FLOW:

1. User visits app (unauthenticated)
   → Redirected to landing page (/)

2. User clicks "Sign In"
   → NextAuth.js sign-in page
   → OAuth provider selection
   → Provider authentication
   → Callback to /api/auth/callback

3. Session created
   → Middleware validates session
   → User redirected to /dashboard

4. Session management
   → Token refresh automatic
   → Logout clears session
   → Protected routes check auth state

SHOW MANAGEMENT FLOW:

1. User navigates to /shows
   → Server fetches show data
   → Renders show table with filters

2. User applies filters
   → Client-side filter state update
   → Table re-renders with filtered data

3. User selects shows (bulk action)
   → Checkbox state managed
   → Bulk toolbar appears

4. User clicks "Add to Tour"
   → Modal opens with tour selection
   → User selects/creates tour
   → Confirm action
   → API call to /api/shows/bulk-update
   → Toast notification on success/error
   → Table refreshes with updated data

TOUR MANAGEMENT FLOW:

1. User navigates to /tours
   → Server fetches tour list
   → Renders tour grid/list

2. User creates new tour
   → Clicks "Create Tour" button
   → Modal opens with form
   → Enters: name, description, dates
   → Submits form
   → API POST to /api/tours
   → Toast success message
   → Redirects to tour details

3. User views tour details (/tours/[id])
   → Server fetches tour data
   → Displays tour info + show list
   → Shows edit/delete options

4. User edits tour
   → Clicks "Edit" button
   → Modal with pre-filled form
   → Updates fields
   → API PATCH to /api/tours/[id]
   → Toast confirmation
   → Page refreshes

5. User removes shows from tour
   → Selects shows in tour table
   → Clicks "Remove from Tour"
   → Confirmation dialog
   → API call updates tour
   → Shows removed from list

CONTACTS & NETWORKING FLOW:

1. User searches for contacts (/contacts)
   → Search bar with filters
   → Real-time search results

2. User sends connection request

3. User receives connection request
   → Notification badge appears

export async function POST(request: Request) {
  try {
    // 1. Authenticate request
    const session = await auth();
    if (!session?.user) {
      return NextResponse.json(
        { error: 'Unauthorized' },
        { status: 401 }
      );
    }

    // 2. Parse request body
    const body = await request.json();
    const { showIds, action, tourId } = body;

    // 3. Validate input
    if (!showIds || !Array.isArray(showIds)) {
      return NextResponse.json(
        { error: 'Invalid show IDs' },
        { status: 400 }
      );
    }

    // 4. Call backend service (MOCK - needs real implementation)
    // const response = await fetch(`${BACKEND_URL}/shows/bulk`, {
    //   method: 'POST',
    //   headers: {
    //     'Authorization': `Bearer ${session.accessToken}`,
    //     'Content-Type': 'application/json'
    //   },
    //   body: JSON.stringify({ showIds, action, tourId })
    // });

    // 5. Mock response for now
    return NextResponse.json({
      success: true,
      updatedCount: showIds.length,
      message: `${showIds.length} shows updated`
    });

  } catch (error) {
    console.error('Bulk update error:', error);

    );
  }
}

const toggleShow = (id: string) => {
  setSelectedShows(prev => {
    const next = new Set(prev);
    if (next.has(id)) {
      next.delete(id);
    } else {
      next.add(id);
    }
    return next;
  });
};

const searchParams = useSearchParams();
const router = useRouter();

const updateFilter = (key: string, value: string) => {
  const params = new URLSearchParams(searchParams);
  if (value) {
    params.set(key, value);
  } else {
    params.delete(key);
  }
  router.push(`?${params.toString()}`);
};

'use client';

function ShowsClient() {
  const [shows, setShows] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetch('/api/shows')
      .then(res => res.json())
      .then(data => {
        setShows(data);
        setLoading(false);
      })
      .catch(error => {
        toast.error('Failed to load shows');
        setLoading(false);
      });
  }, []);

  if (loading) return <Skeleton />;

  return <ShowTable shows={shows} />;
}

Configuration:

export const { handlers, signIn, signOut, auth } = NextAuth({
  providers: [
    GitHub({
      clientId: process.env.GITHUB_ID,
      clientSecret: process.env.GITHUB_SECRET,
    }),
    // Add more providers
  ],
  pages: {
    signIn: '/auth/signin',
  },
  callbacks: {
    async jwt({ token, user, account }) {
      // Add custom fields to token
      if (account && user) {
        token.accessToken = account.access_token;
        token.userId = user.id;
      }
      return token;
    },
    async session({ session, token }) {
      // Add custom fields to session
      session.user.id = token.userId;
      session.accessToken = token.accessToken;
      return session;
    },
  },
});
