================================================================================
WHY THIS HAPPENS
================================================================================

GOOGLE'S RESTRICTION TYPES ARE CONFUSING:

1. APPLICATION RESTRICTIONS (How the key can be used):
   - None: Any application can use it (least secure, best for dev)
   - HTTP referrers: Only specific websites (for browser/frontend)
   - IP addresses: Only specific servers (for backend)
   - Android apps: Only specific Android apps
   - iOS apps: Only specific iOS apps

2. API RESTRICTIONS (Which Google APIs can be called):
   - Don't restrict key: Can call any Google API
   - Restrict key: Only specific APIs can be called

THE PROBLEM:
- You may have "Don't restrict key" for #2 (API restrictions)
- But still have "HTTP referrers" for #1 (Application restrictions)
- The Directions REST API doesn't work with HTTP referrer restrictions
- Even though the JavaScript API (DirectionsService) should work

THE SOLUTION:
- Set #1 (Application restrictions) to "NONE"
- Set #2 (API restrictions) to "Don't restrict key"
- This makes the key work everywhere (not secure for production!)
- After testing works, you can add back specific restrictions
